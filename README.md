# Btc Profit Lock Guide

create a professional landing page for btcusd bot

Hero: a headline, two buttons (Download and Install guide), and an animated scan radar that echoes the bot's dashboard.

What the bot does: six short points covering stops on every trade, signal scoring, profit locking, loss limits, the dashboard, and the trade log.

Download: a button for the .mq5 file plus a requirements table.

Installation guide: seven steps from installing MetaTrader 5 through allowing the ranking address.

Ranking: how the Rank button works, a sortable leaderboard, and a username lookup that opens rankBase plus the username.

FAQ and risk notice: an expandable FAQ and a risk notice, with "For Support: testing@btcbot.com" in the footer.
